## 武蔵小杉で仲介手数料を安く抑える方法は？

**結論：物件を探し始める前に、仲介手数料の体系を公開している会社を選ぶことです。** 賃貸なら「家賃の半額（0.5ヶ月分＋税）」、売買なら「法定上限の半額」のように最初から定率で決まっている会社を選べば、物件ごとの交渉は不要です。

武蔵小杉は家賃も売買価格も高めのエリアなので、手数料の「率」の差がそのまま数万円から数十万円の差になります。この記事では、上限額の仕組み、具体的な差額、安い会社を選ぶときの注意点を順に説明します。

## 仲介手数料の上限はいくらですか？

**結論：賃貸は「家賃1ヶ月分＋消費税」、売買（400万円超）は「成約価格の3%＋6万円＋消費税」が上限です。** これは宅地建物取引業法にもとづく上限で、どの会社に頼んでも上限を超えることはありません。

- **賃貸**：貸主と借主から受け取れる合計の上限が家賃1ヶ月分＋税です。借主が負担する額は原則0.5ヶ月分＋税で、借主の承諾がある場合に1ヶ月分＋税まで受け取れる、という整理になっています（※承諾の取り方については要確認事項があります。契約前に確認してください）。
- **売買**：成約価格が400万円を超える場合、「成約価格の3%＋6万円＋税」が上限の速算式です。
- **低額物件の特例**：2024年7月以降、800万円以下の物件については、上限が「30万円＋税」まで引き上げられる特例があります（※適用条件は要確認）。武蔵小杉のマンションでは該当するケースは少ないと考えられます。

重要なのは、**これらは「上限」であって「定価」ではない**という点です。下限は決められていないため、会社ごとに自由に設定できます。

## 武蔵小杉の家賃・価格水準だと、手数料はいくら違いますか？

**結論：家賃15万円の賃貸で約8万円、7,000万円の売買で約119万円の差になります。** 以下は上限額と半額の場合を並べた試算です（金額はあくまで例で、消費税10%で計算しています）。

### 賃貸の例：家賃15万円

| 手数料体系 | 計算 | 借主の負担額 |
| --- | --- | --- |
| 上限（1ヶ月分＋税） | 150,000円 × 1.1 | 165,000円 |
| 半額（0.5ヶ月分＋税） | 75,000円 × 1.1 | 82,500円 |
| **差額** | | **82,500円** |

### 売買の例：成約価格7,000万円

| 手数料体系 | 計算 | 負担額 |
| --- | --- | --- |
| 上限（3%＋6万円＋税） | (2,100,000 + 60,000) × 1.1 | 2,376,000円 |
| 半額（1.5%＋3万円＋税） | (1,050,000 + 30,000) × 1.1 | 1,188,000円 |
| **差額** | | **1,188,000円** |

売買では差額が100万円を超えます。武蔵小杉のタワーマンションのように価格が高い物件ほど、率の差が効いてきます。

## 手数料が安い会社を選ぶとき、注意点はありますか？

**結論：紹介できる物件の範囲、サービスの範囲、手数料以外の費用の3点を確認してください。** 安い理由が「省ける工程を省いているから」なのか「別の名目で回収しているから」なのかで意味が変わります。

1. **紹介できる物件の範囲**：賃貸・売買とも、多くの物件は業者間の情報網で共有されており、原則としてどの仲介会社からでも申し込めます。ただし一部に自社のみで扱う物件もあります。気になる物件を先に見つけてから「この物件を扱えますか」と聞くのが確実です。
2. **サービスの範囲**：内見の同行、条件交渉、契約書類の説明、引き渡しまでの段取りをどこまでやるかは会社によって差があります。来店不要のオンライン対応かどうかも確認ポイントです。
3. **手数料以外の費用**：賃貸では「事務手数料」「書類作成費」「消毒費」、売買では「ローン事務代行手数料」などが上乗せされる例があります。仲介手数料の率だけでなく、**見積書の総額**で比較してください。

## 手数料を抑える具体的な手順は？

**結論：「会社を先に決める → 物件を探す → 総額の見積りで比較する」の順が効率的です。**

1. **手数料体系が明確な会社を探す**：サイトに率が書いてある会社を候補にします。
2. **その会社で物件を探す、または気になる物件を持ち込む**：ポータルサイトで見つけた物件も、扱えるかどうか確認してもらえます。
3. **見積書で総額を比較する**：仲介手数料に加えて、他の名目の費用が無いか確認します。
4. **契約前に重要事項説明で再確認する**：手数料の額と支払時期は、契約書類にも明記されます。
